# KZ AutoEQ Tunings — V1

Six experimental tuning identities for the KZ Duonic:

1. Natural
2. Premium
3. Dreamy
4. Cinematic
5. EDM + Rap
6. Subliminal

Each profile is supplied as:
- Wavelet AutoEQ / GraphicEQ
- Poweramp Parametric EQ JSON
- Universal PEQ
- General 10-band Graphic EQ

## Tuning philosophy

The project aims to reduce unwanted bass masking while preserving the Duonic's character,
with particular attention to natural vocal presentation, instrument clarity, separation,
and perceived spaciousness.

All profiles include a small kick-bass restoration compared with the earlier versions.

## Important

These are V1 experimental/listening presets. The measured frequency response is used as a
reference, but final tuning should be validated by listening and iterated before publication
as a finished recommendation.

Wavelet files use the fixed 127-point AutoEQ-style GraphicEQ format.
